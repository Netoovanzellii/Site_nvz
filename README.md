# NVZ

Site institucional da **NVZ**, consultoria e desenvolvimento de software focada em automação de processos, integração de sistemas, BI e Inteligência Artificial aplicada a empresas.

Site no ar: https://site-tau-beige.vercel.app

## Sobre

A NVZ transforma dados e processos empresariais manuais em automação, dashboards de BI, IA aplicada e sistemas integrados sob medida — nascida da experiência prática de resolver esses problemas no dia a dia de operações reais (ERP, planilhas, integrações entre sistemas legados e novos).

## Stack

- React 18 + TypeScript + Vite
- Tailwind CSS + shadcn/ui (Radix primitives)
- React Router, React Query, React Hook Form + Zod
- Vitest + Testing Library para testes de componente

## Rodando localmente

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # build de produção
npm run test      # roda a suite de testes
```
